# talk2shorts

[English](../README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [中文](README.zh.md) · [Português](README.pt.md) · [हिन्दी](README.hi.md) · [Bahasa Indonesia](README.id.md) · [Français](README.fr.md) · **Русский**

Превращает фрагмент горизонтального выступления, лекции или интервью в вертикальный шортс одной командой. Кадр следует за говорящим, субтитры создаются по речи и размещаются там, где **их не закроют кнопки YouTube Shorts, TikTok и Instagram Reels**, а громкость приводится к -14 LUFS.

```
talk2shorts interview.mp4 --start 0:10 --end 0:50 --title "What it's like to live in space"
```

## Что он делает

1. **Следит за лицом.** Детектор YuNet из OpenCV находит говорящего пять раз в секунду; кадр 9:16 следует за крупными перемещениями и игнорирует мелкие, поэтому не дрожит при каждом жесте.
2. **Создаёт субтитры.** [faster-whisper](https://github.com/SYSTRAN/faster-whisper) расшифровывает фрагмент с таймингом каждого слова, а talk2shorts группирует слова в субтитры не более чем из двух сбалансированных строк, разбивая их по паузам, концам предложений и запятым и никогда не оставляя одно слово отдельно. Можно также использовать собственный SRT.
3. **Убирает текст из-под элементов плееров.** Субтитры и заголовок размещаются в области, свободной на всех трёх платформах; используются зоны, измеренные по собственным шаблонам каждой платформы в [shorts-safezone](https://github.com/CokeRoach/shorts-safezone). В TikTok эта область внизу узкая (кнопки расположены справа), поэтому субтитры немного смещены влево от центра; укажите `--platforms youtube`, чтобы использовать только более широкую область YouTube.
4. **Настраивает звук.** Двухпроходная нормализация громкости до -14 LUFS, истинный пик (true peak) ниже -1.5 dB, с затуханием в конце.
5. **Проверяет результат.** Отчёт показывает, свободны ли все субтитры и заголовок на каждой платформе, измеренную громкость, как часто удавалось найти лицо и не закрывает ли заголовок лицо.

Всё работает на вашем компьютере. Ничего никуда не загружается.

## Установка

Нужен [ffmpeg](https://ffmpeg.org) в PATH (с libass, как в большинстве сборок), затем:

```
pip install "talk2shorts[captions]"
```

Можно не указывать `[captions]`, если вы всегда будете передавать собственный `--srt`. Модель для поиска лиц (230 KB, лицензия MIT) скачивается один раз при первом использовании и проверяется по контрольной сумме SHA-256.

## Использование

```
talk2shorts talk.mp4 --start 3:33 --end 4:25
talk2shorts talk.mp4 --start 213 --end 265 --title "Where does happiness come from?" --language en
talk2shorts talk.mp4 --start 3:33 --end 4:25 --srt talk.srt          # your captions, in source time
talk2shorts talk.mp4 --start 3:33 --end 4:25 --model large-v3        # better captions, slower
talk2shorts talk.mp4 --start 3:33 --end 4:25 --platforms youtube     # only YouTube's buttons
```

Команда создаёт `talk_short.mp4`, субтитры в файле `talk_short.srt` и `talk_short.report.json`:

```json
{
  "face_found_share": 1.0,
  "captions": 22,
  "caption_safe": { "youtube": [], "tiktok": [], "reels": [] },
  "title_safe":   { "youtube": [], "tiktok": [], "reels": [] },
  "title_covers_face": true,
  "loudness": { "source": -23.05, "output": -14.05 }
}
```

Пустой список означает, что на этой платформе текст ничем не закрыт. Если закрыт хоть какой-то текст, команда завершается с кодом 1, поэтому её можно использовать как проверку в пакетном скрипте.

| Параметр | По умолчанию | |
| --- | --- | --- |
| `--title` | нет | Показывается сверху первые 3 секунды; `\n` переносит строку |
| `--srt` | распознавание речи | Собственные субтитры с таймингом по исходному видео |
| `--model` | `small` | Модель faster-whisper: `tiny`, `base`, `small`, `medium`, `large-v3` |
| `--language` | определяется автоматически | Код языка речи, например `en`, `ko`, `ja` |
| `--lines` | `2` | Количество строк в субтитре: 1 или 2 |
| `--platforms` | `all` | `youtube`, `tiktok`, `reels` или список через запятую |
| `--font` | жирный системный шрифт для данной письменности | Файл шрифта для субтитров и заголовка |
| `--no-track` | выкл. | Держать кадр по центру |
| `--no-captions` | выкл. | Без субтитров |

GPU ускоряет распознавание речи, если установлены библиотеки CUDA для faster-whisper; без них talk2shorts автоматически переключается на CPU.

## Языки

Распознавание речи поддерживает языки, которые знает faster-whisper (около 99). Шрифт субтитров выбирается по письменности текста, поэтому для каждого языка используется жирное начертание, в котором есть все его буквы:

| Письменность | Windows | macOS | Linux |
| --- | --- | --- | --- |
| Корейская | Malgun Gothic | Apple SD Gothic Neo | Noto Sans CJK |
| Японская | Yu Gothic | Hiragino Sans | Noto Sans CJK |
| Китайская | Microsoft YaHei | PingFang | Noto Sans CJK |
| Хинди (деванагари) | Nirmala UI | Kohinoor | Noto Sans Devanagari |
| Арабская | Segoe UI | Geeza Pro | Noto Sans Arabic |
| Тайская | Leelawadee UI | Thonburi | Noto Sans Thai |
| Латиница, кириллица | Segoe UI | Helvetica Neue | Noto Sans |

Текст только из иероглифов хань считается китайским; укажите `--language ja` для японского текста, написанного без каны. Арабский текст располагается справа налево. Субтитры переносятся после концов предложений и запятых (в том числе 、 и ，), строка никогда не начинается с закрывающего знака препинания, а знаки гласных в тайском письме и деванагари остаются при своей букве. Чтобы выбрать свой шрифт, используйте `--font`.

## Ограничения

- Лучше всего работает, когда в кадре один говорящий. Если два человека находятся рядом, кадр следует за более крупным лицом.
- Субтитры, уже вшитые в исходное видео, остаются на изображении.
- Если голова говорящего находится у верхнего края кадра, заголовок может её закрыть; отчёт сообщает об этом (`title_covers_face`). Помогает более короткий заголовок в одну строку.
- Тайский язык пишется без пробелов между словами, а у talk2shorts нет тайского словаря, поэтому длинная тайская строка может разорваться посреди слова.
- Распознавание речи допускает ошибки, особенно в именах. Проверьте `.srt`, исправьте его и заново отрендерите видео с `--srt`.
